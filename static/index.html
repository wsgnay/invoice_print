使用说明

1. 选择左侧工具，拖入或选择文件。

2. 勾选需要的页面，用 ↑ ↓ 调整顺序。不同工具的文件清单独立保存。

3. 发票按每页一张自动提取含税总额；图片和扫描件自动使用 OCR 识别。识别失败可点击“重新识别金额”，或通过“校对”修正；重新识别会保留已手动校对的金额。当前按人民币汇总，不进行币种换算。

4. PDF 工具可合并多个文件、按页码提取或逐页拆分。

5. 导出 PDF 后，用阅读器以“实际大小”打印。PDF 转 Word 仅提供基础文字提取，扫描页保留为图片。

单文件不超过 50 MB / 200 页，每次导出合计不超过 150 MB / 200 页。加密 PDF 需先解密。
