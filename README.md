# 纸间 Paperdesk

本机运行的中文文档工具 MVP。Python + FastAPI 提供处理服务，前端无需构建。

## 启动

需要 Python 3.11 或更新版本。在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

首次运行会创建 `.venv` 并安装依赖。本机访问 http://127.0.0.1:8765；启动窗口还会显示局域网访问地址。关闭启动终端即可停止服务。

公网部署请参考 [DEPLOY.md](DEPLOY.md)，项目已包含 Docker、Caddy 自动 HTTPS 和健康检查配置。

也可以手动安装与启动：

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 已实现

- 发票：批量导入 PDF 或图片，自动提取“价税合计（小写）”等明确合计字段；文字层缺失时使用本机 OCR，支持重新识别与人工校对，并以整数分汇总人民币金额；每张 A4 放 1、2（上下）、4 张，支持横向和边距设置，导出 PDF。
- PDF：多个文件合并、页面勾选、上下移动排序、页码范围提取、逐页拆分为 ZIP。
- 图片：JPG / PNG / WebP 转 PDF，自动处理 EXIF 方向及透明背景。
- Word：文字型 PDF 提取为可编辑段落并保留分页；扫描页以整页图片插入 DOCX。
- 文件拖放、缩略图、分页排版预览、错误提示；四个工具保留独立的临时清单。

## MVP 边界

- 图片与扫描发票使用本机 OCR，首次识别会比文字型 PDF 慢。OCR 结果会标明来源，并保留“校对”入口；无法唯一确定合计金额时标为“需复核”，不计入小计。一页多张发票请先分开；一张多页发票须避免重复计算总额。仅按人民币汇总，不做币种识别或换算。
- PDF 转 Word 为基础文字转换，不还原原布局、复杂表格和图文混排，扫描页文字不可编辑。
- 导出打印 PDF 不包含金额汇总表，不修改原文件。对带签名的 PDF 做编辑或排版不会保留原签名有效性。
- 单文件最大 50 MB、200 页；当前工具最多 200 页；每次导出原文件合计最多 150 MB。
- 不支持加密 PDF、OFD、HEIC。加密文件需先解密。
- 文件只在本机处理，不主动保存上传原件；上传框架可能使用请求级临时缓存。刷新后浏览器清单清空，导出的文件由浏览器保存。
- 本机启动脚本监听局域网地址，局域网内知道地址的设备均可访问。公网容器配置包含 HTTPS、Host 校验和基础容器隔离，但此版本仍没有用户系统、访问认证、限流或后台任务队列。
- PyMuPDF 采用 AGPL / 商业双许可，闭源分发或商业部署前需评估许可或替换处理引擎。
